# Python GUI File Manager Base & Application

このプロジェクトは、Python (PySide6) でファイルやディレクトリを操作するGUIアプリケーションを開発するためのクリーンな**データモデルおよびリポジトリパターンのベースクラス群**と、それを利用して構築された**シンプルなGUIアプリケーション**の実装サンプルです。

---

## 📂 プロジェクト構成

```
PythonBaseClasses/
├── BaseNodeObject.py   # データモデル（ノード情報・アイコン・メタデータの保持）
├── FilerRepository.py  # リポジトリ（ファイルシステムの読み書き操作のカプセル化）
├── main.py             # GUIアプリケーション (PySide6 / Tokyo Nightダークテーマ)
└── README.md           # 本書
```

## 🛠️ アーキテクチャと役割

本プロジェクトは、GUI表示ロジックとファイル操作の実ロジックを疎結合に保つため、**リポジトリパターン**および**オブジェクト指向のポリモーフィズム**を意識した実装を行っています。

### 1. データモデル層 (`BaseNodeObject.py`)

ファイル・ディレクトリ要素は `BaseNodeObject` の派生クラスとして表されます。UIに必要な表現（アイコン、ファイルタイプ名、サイズ表現）や、ファイルメタデータ問い合わせは、すべてモデル内にカプセル化されています。

- **`BaseNodeObject`**: 基底クラス。パス・名前・選択状態を管理します。
  - `is_selected`: 選択状態 (変更時に `updated` シグナルを発火)
  - `exists`: ファイル/フォルダの存在確認 (bool)
  - `modified_time` / `created_time`: タイムスタンプ (float)
  - `icon` / `type_name` / `size_str`: UI表示用プロパティ（規定値はファイル用）
- **`FileNodeObject`**: ファイル表現。拡張子に基づいた絵文字や、ファイルサイズ、タイプ名を返します。
- **`DirectoryNodeObject`**: ディレクトリ表現。配下の子ノードリスト（`children`）を保持します。

### 2. データアクセス・操作層 (`FilerRepository.py`)
ファイルシステムの読み書き操作をカプセル化するリポジトリです。GUI層（`main.py`）から `os` や `shutil` といったOS標準モジュールへの直接呼び出しを無くし、テストや拡張を容易にします。

- `get_directory_node(dir_path)`: 指定されたパスのディレクトリノードを作成し、中身のノード群を詰めて返す。
- `create_directory(parent_path, name)`: 指定された親ディレクトリ配下に新しいディレクトリを作成する。
- `create_file(parent_path, name)`: 指定された親ディレクトリ配下に新しい空ファイルを作成する。
- `rename_node(node_path, new_name)`: 指定されたパスのファイル名またはフォルダ名を変更する。
- `delete_node(node_path)`: 指定されたパスのファイルまたはフォルダを削除する。

### 3. UI・プレゼンテーション層 (`main.py`)
PySide6を用いて構築されたデスクトップ向けGUIです。シンプルなUIと使い勝手の良さを重視したデザインを採用しています。

- **サイドバー**: ホーム・ドキュメント・ダウンロードなどのよく使う場所へのショートカット。
- **ナビゲーション**: 「戻る」「進む」「上へ」「更新」履歴機能と、直接入力可能なパスバー。
- **テーブルビュー**: 列ソート（数値/時間順に正しく対応）、複数選択チェックボックスの同期。
- **コンテキストメニュー**: テーブル内右クリックによる「開く」「名前の変更」「削除」「新規フォルダ作成」「新規ファイル作成」のアクション実行。
- **詳細パネル**: 選択したノードのリアルタイムなメタデータ・選択状態トグルの表示。

## 🚀 セットアップと実行

### 動作環境
- Python 3.12 以上
- PySide6

### インストール手順

1. **仮想環境の作成**
   ```bash
   python3 -m venv venv
   ```

2. **依存関係のインストール**
   ```bash
   ./venv/bin/pip install PySide6
   ```

3. **アプリケーションの実行**
   ```bash
   ./venv/bin/python main.py
   ```
